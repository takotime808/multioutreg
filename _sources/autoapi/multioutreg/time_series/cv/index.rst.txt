.. py:function:: walk_forward_splits(n: int, min_train: int, horizon: int, step: int = 1, max_train: Optional[int] = None) -> Iterator[Tuple[numpy.ndarray, numpy.ndarray]]

   Generate walk-forward (train_idx, test_idx) pairs.

   :param n: Total series length.
   :type n: int
   :param min_train: Minimum number of training observations.
   :type min_train: int
   :param horizon: Forecast horizon (test window size).
   :type horizon: int
   :param step: Number of steps to advance the window between folds.
   :type step: int, default 1
   :param max_train: If given, applies a rolling window (training set size capped at max_train).
                     None => expanding window (training set always grows).
   :type max_train: int | None

   :Yields: * **train_idx** (*np.ndarray of int*)
            * **test_idx** (*np.ndarray of int*)

   :raises ValueError: If ``step`` or ``horizon`` is below 1 (``step <= 0`` would never end).


.. py:class:: WalkForwardCV(min_train: int = 30, horizon: int = 1, step: int = 1, max_train: Optional[int] = None, seasonality: int = 1)

   Walk-forward cross-validator for time series forecasters.

   Fits the forecaster on each training fold and evaluates on the test fold,
   computing SMAPE, MASE, and WQL (when quantile forecasts are available).

   The forecaster must implement::

       forecaster.fit(train_series)   # 1D array or pd.Series
       forecaster.predict(horizon, quantiles=quantiles)  # -> ForecastResult

   :param min_train: Minimum training observations.
   :type min_train: int, default 30
   :param horizon: Steps to forecast per fold.
   :type horizon: int, default 1
   :param step: Steps to advance the training window between folds.
   :type step: int, default 1
   :param max_train: Expanding (None) or rolling window.
   :type max_train: int | None, default None
   :param seasonality: Seasonal period used in the MASE denominator.
   :type seasonality: int, default 1

   .. admonition:: Examples

      >>> cv = WalkForwardCV(min_train=50, horizon=5, step=5)
      >>> results = cv.evaluate(series, forecaster)
      >>> print(cv.summary(results))


   .. py:attribute:: min_train
      :value: 30



   .. py:attribute:: horizon
      :value: 1



   .. py:attribute:: step
      :value: 1



   .. py:attribute:: max_train
      :value: None



   .. py:attribute:: seasonality
      :value: 1
