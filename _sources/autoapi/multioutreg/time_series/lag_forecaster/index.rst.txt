.. py:class:: LagFeatureForecaster(surrogate: Any, n_lags: int = 12, horizon: int = 1, uncertainty: str = 'return_std', include_time_features: bool = False, include_rolling_windows: bool = False, rolling_windows: Sequence[int] = (4, 8, 24))

   Wrap any surrogate or sklearn estimator to forecast a time series via lag features.

   Converts a 1D series to a tabular (X_lag, y) sliding-window matrix, fits the
   surrogate, then iterates multi-step predictions by feeding each step's prediction
   back as the next row's lag context.

   Uncertainty is propagated using one of three strategies:

   - ``"conformal"``  : calls ``wrap_conformal()`` / ``conformal_predict()`` if the
                        surrogate exposes a ``ConformalMixin`` API; falls back to
                        ``"return_std"`` otherwise.
   - ``"return_std"`` : calls ``surrogate.predict(X, return_std=True)`` to get std.
   - ``"none"``       : point prediction only; lower/upper equal the point prediction.

   :param surrogate: Fitted or unfitted sklearn-compatible estimator or BaseSurrogate.
   :type surrogate: Any
   :param n_lags: Number of historical steps used as features.
   :type n_lags: int, default 12
   :param horizon: Steps to forecast ahead in a single call to ``predict()``.
   :type horizon: int, default 1
   :param uncertainty: Uncertainty strategy: ``"conformal"``, ``"return_std"``, or ``"none"``.
   :type uncertainty: str, default "return_std"
   :param include_time_features: Append sin/cos-encoded calendar features (requires DatetimeIndex).
   :type include_time_features: bool, default False
   :param include_rolling_windows: Append rolling mean/std columns to the lag matrix.
   :type include_rolling_windows: bool, default False
   :param rolling_windows: Window sizes used when include_rolling_windows=True.
   :type rolling_windows: sequence of int, default (4, 8, 24)
