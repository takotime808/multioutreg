   Bases: :py:obj:`multioutreg.surrogates.base_sklearn.BaseSurrogate`


   CatBoost regression surrogate with optional native uncertainty.

   Wraps :class:`catboost.CatBoostRegressor` in a ``MultiOutputRegressor``.
   When ``use_uncertainty=True`` (default), trains with
   ``loss_function="RMSEWithUncertainty"`` and returns aleatoric + epistemic
   variance via CatBoost's virtual ensemble mechanism — the only tree-based
   surrogate in this library with native (non-conformal) uncertainty output.

   Requires the optional ``catboost`` package::

       pip install catboost

   :param n_estimators: Number of boosting iterations.
   :type n_estimators: int, default 200
   :param learning_rate: Shrinkage applied to each tree.
   :type learning_rate: float, default 0.05
   :param depth: Maximum tree depth.
   :type depth: int, default 6
   :param use_uncertainty: If True, trains with ``loss_function="RMSEWithUncertainty"`` and
                           returns native uncertainty from ``virtual_ensembles_predict``.
                           If False, uses standard RMSE loss and returns zeros for std.
   :type use_uncertainty: bool, default True
   :param virtual_ensembles_count: Number of virtual ensembles used when estimating uncertainty.
                                   Higher values give smoother variance estimates at extra compute cost.
   :type virtual_ensembles_count: int, default 10
   :param verbose: CatBoost verbosity. ``False`` / ``0`` suppresses all output.
   :type verbose: bool | int, default False
   :param \*\*kwargs: Additional keyword arguments forwarded to ``CatBoostRegressor``.
