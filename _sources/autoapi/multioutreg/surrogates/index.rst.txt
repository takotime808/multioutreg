.. py:class:: ConformalMixin

   Bases: :py:obj:`multioutreg.surrogates._clone.CloneMixin`


   Mixin providing conformal prediction calibration and inference.

   Any surrogate that implements ``fit(X, Y)`` and ``predict(X)`` can
   inherit this mixin to gain ``wrap_conformal`` and ``conformal_predict``
   without depending on sklearn's ``MultiOutputRegressor``.

   Subclasses must implement ``_conformal_point_predict(X)`` that returns
   an ``(n_samples, n_outputs)`` array. By default this calls
   ``self.predict(X)`` with no keyword arguments.

.. py:class:: BNNSurrogate(hidden_layer_sizes: tuple = (128, 64), dropout_p: float = 0.1, n_mc_samples: int = 30, max_epochs: int = 500, learning_rate: float = 0.001, batch_size: int = 64, patience: int = 30, random_state: int | None = None, loss: str = 'nll')

   Bases: :py:obj:`multioutreg.surrogates.conformal_mixin.ConformalMixin`


   Bayesian Neural Network surrogate with MC Dropout uncertainty.

   Trains a fully-connected network with dropout and approximates the
   posterior predictive distribution at inference by running ``n_mc_samples``
   stochastic forward passes with dropout active.

   With ``loss="nll"`` (default) the network also has a variance head and is
   trained on the Gaussian negative log-likelihood (heteroscedastic MC
   Dropout, Kendall & Gal 2017). Predictive variance = mean of the predicted
   noise variances (aleatoric) + variance of the MC means (epistemic).

   With ``loss="mse"`` the std is the spread of the MC passes only. That is
   epistemic only: it ignores the noise in y, so its intervals under-cover
   on noisy data. Use it only for noise-free data or wrap it with conformal
   prediction.

   :param hidden_layer_sizes:
   :type hidden_layer_sizes: tuple[int, ...], default (128, 64)
   :param dropout_p: Dropout probability applied after every hidden layer.
   :type dropout_p: float, default 0.1
   :param n_mc_samples: Number of stochastic forward passes used to estimate predictive std.
                        Set to 1 for deterministic point-estimate mode.
   :type n_mc_samples: int, default 30
   :param max_epochs:
   :type max_epochs: int, default 500
   :param learning_rate:
   :type learning_rate: float, default 1e-3
   :param batch_size:
   :type batch_size: int, default 64
   :param patience: Early-stopping patience (epochs without improvement).
   :type patience: int, default 30
   :param random_state:
   :type random_state: int | None, default None
   :param loss: ``"nll"`` learns the noise variance (aleatoric + epistemic std);
                ``"mse"`` gives the epistemic-only MC spread.
   :type loss: {"nll", "mse"}, default "nll"


   .. py:attribute:: loss
      :value: 'nll'



   .. py:attribute:: hidden_layer_sizes
      :value: (128, 64)



   .. py:attribute:: dropout_p
      :value: 0.1



   .. py:attribute:: n_mc_samples
      :value: 30



   .. py:attribute:: max_epochs
      :value: 500



   .. py:attribute:: learning_rate
      :value: 0.001

.. py:class:: MultiFidelitySurrogate(surrogate_cls, fidelity_levels: Iterable[str])

   Bases: :py:obj:`multioutreg.surrogates._clone.CloneMixin`


   Independent surrogate per fidelity level (no information transfer).

   Each level's model is fitted only on that level's data, and
   ``predict(X, level=...)`` uses only that level's model: the high-fidelity
   prediction ignores the low-fidelity data entirely.  This is a baseline
   (and a container for single-level use, e.g. in
   ``AutoDetectMultiOutputRegressor``), not a multi-fidelity model.  For
   models that use the cheaper levels to predict the expensive one, use
   ``StackedVFMSurrogate`` (any number of levels) or
   ``AdditiveCorrectionVFM`` (two levels, ``f_hi = rho * f_lo + delta``).

   ``predict`` defaults to the *last* (highest) level, the one a
   multi-fidelity study is usually after; pass ``level`` for any other.

.. py:class:: StackedVFMSurrogate(fidelity_levels: List[str], surrogate_cls=None, surrogate_params: Union[dict, List[dict], None] = None, augment_with_std: bool = False, output_dim_mismatch: Literal['error', 'truncate', 'pad'] = 'error', oof_cv: Optional[int] = 5, random_state: Optional[int] = 0, n_mc_samples: int = 100)

   Bases: :py:obj:`multioutreg.surrogates.conformal_mixin.ConformalMixin`


   Stacked Variable Fidelity Model surrogate.

   Implements the recursive feature-augmentation approach described in
   Perdikaris et al. (2017).  At each fidelity level k, the input feature
   matrix is augmented with the predictions (and optionally predicted stds)
   of all lower-level surrogates before fitting, enabling the higher-fidelity
   surrogate to learn a nonlinear correction over the lower-fidelity
   prediction.

   :param fidelity_levels: Ordered list of fidelity level names from lowest to highest.
                           Must have at least 2 elements.
   :type fidelity_levels: list[str]
   :param surrogate_cls: Surrogate class(es) to instantiate per level.  A single class is
                         used for all levels.  A list must have the same length as
                         ``fidelity_levels`` and is used element-wise (heterogeneous experts).
                         Defaults to ``RandomForestSurrogate``.
   :type surrogate_cls: type | list[type] | None
   :param surrogate_params: Constructor kwargs for each surrogate.  A single dict applies to all
                            levels; a list is paired element-wise with ``surrogate_cls``.
   :type surrogate_params: dict | list[dict] | None
   :param augment_with_std: If True, the predicted standard deviation of level k is also appended
                            to the feature matrix for level k+1 alongside the predictions.
                            Requires each surrogate to support ``predict(X, return_std=True)``.

                            Note: std features are treated as deterministic inputs, which is an
                            approximation (see Perdikaris et al. 2017).  If the surrogate does not
                            natively produce uncertainty (e.g. LinearRegressionSurrogate), the std
                            columns will be all-zero and uninformative.
   :type augment_with_std: bool, default False
   :param output_dim_mismatch: Policy when the augmented feature count at predict time does not match
                               what was seen at fit time (can arise if surrogates are swapped via
                               ``set_params`` without re-fitting).
                               ``"error"`` raises ValueError.
                               ``"truncate"`` clips extra augmentation columns.
                               ``"pad"`` zero-pads missing augmentation columns.
   :type output_dim_mismatch: {"error", "truncate", "pad"}, default "error"
   :param oof_cv: Folds used for out-of-fold lower-level predictions while fitting.
                  When a level's training inputs are also training inputs of a lower
                  level (nested designs), the lower model's predictions there are
                  in-sample and over-accurate; the higher level then over-trusts them
                  and does worse at new points. Those rows instead get predictions from
                  a lower model fitted without them. Rows that are not lower-level
                  training points use the full model, as does ``predict``. ``None`` or
                  ``0`` uses in-sample predictions (the old behaviour).
   :type oof_cv: int or None, default 5
   :param random_state: Seed for the out-of-fold split and the Monte Carlo draws.
   :type random_state: int or None, default 0
   :param n_mc_samples: Draws used by ``predict(..., return_std=True)`` to propagate
                        lower-level uncertainty. Each lower level's prediction is replaced
                        by a sample from ``N(mean, std)`` and passed up the stack; the
                        returned std combines the top level's own std with the spread of its
                        mean across draws. Without this the top level treats lower-level
                        predictions as exact and its intervals are much too narrow. ``0``
                        returns the top level's std alone (the old behaviour). Lower-level
                        surrogates must support ``predict(X, return_std=True)``.
   :type n_mc_samples: int, default 100

   .. attribute:: surrogates_

      Fitted surrogate per level, keyed by level name.

      :type: dict[str, surrogate]

   .. attribute:: n_outputs_per_level_

      Number of outputs for each level as seen at fit time.

      :type: dict[str, int]

   .. attribute:: augmented_n_features_per_level_

      Total number of features (original + augmented) used for each level.

      :type: dict[str, int]

   .. attribute:: n_features_in_

      Number of raw input features (from level 0 data).

      :type: int

   .. admonition:: Examples

      >>> import numpy as np
      >>> from multioutreg.surrogates import StackedVFMSurrogate
      >>> from multioutreg.surrogates import GaussianProcessSurrogate, RandomForestSurrogate
      >>> rng = np.random.default_rng(0)
      >>> X_lo = rng.standard_normal((80, 3))
      >>> Y_lo = np.sin(X_lo).sum(axis=1, keepdims=True)
      >>> X_hi = rng.standard_normal((30, 3))
      >>> Y_hi = np.sin(X_hi).sum(axis=1, keepdims=True) + 0.1 * rng.standard_normal((30, 1))
      >>> model = StackedVFMSurrogate(
      ...     fidelity_levels=["lo", "hi"],
      ...     surrogate_cls=[RandomForestSurrogate, GaussianProcessSurrogate],
      ... )
      >>> model.fit({"lo": (X_lo, Y_lo), "hi": (X_hi, Y_hi)})
      StackedVFMSurrogate(...)
      >>> y_pred = model.predict(X_hi)
      >>> y_pred.shape
      (30, 1)

   .. py:method:: predict(X: numpy.ndarray, level: Optional[str] = None, return_std: bool = False) -> Union[numpy.ndarray, Tuple[numpy.ndarray, numpy.ndarray]]

      Predict at a specified fidelity level.

      :param X: Raw (un-augmented) input features.  Must match ``n_features_in_``.
      :type X: np.ndarray, shape (n_samples, n_features)
      :param level: Fidelity level to predict at.  Defaults to the highest level
                    (last entry in ``fidelity_levels``).
      :type level: str or None
      :param return_std: If True, also return the predictive standard deviation. Lower-level
                         uncertainty is propagated by Monte Carlo (``n_mc_samples`` draws):
                         the std is the root mean square, over draws, of the top level's
                         std and of its mean's deviation from ``y_pred``. ``y_pred`` itself
                         is the plug-in prediction, the same as with ``return_std=False``.
                         With ``n_mc_samples=0`` only the top level's own std is returned,
                         which underestimates the total uncertainty.
      :type return_std: bool, default False

      :returns: * **y_pred** (*np.ndarray, shape (n_samples, n_outputs)*)
                * **y_std** (*np.ndarray, shape (n_samples, n_outputs)  [only if return_std]*)

      :raises ValueError: If ``level`` is not in ``fidelity_levels``.
      :raises AttributeError: If the model has not been fitted.

.. py:class:: AdditiveCorrectionVFM(lo_surrogate_cls=None, hi_surrogate_cls=None, lo_surrogate_params: Optional[dict] = None, hi_surrogate_params: Optional[dict] = None, rho: Union[Literal['fit'], float] = 'fit', oof_cv: Optional[int] = 5, random_state: Optional[int] = 0)

   Bases: :py:obj:`multioutreg.surrogates.conformal_mixin.ConformalMixin`


   Two-level autoregressive correction (Kennedy-O'Hagan AR1) surrogate.

   The high-fidelity response is modelled as:

       f_hi(x) = rho * f_lo(x) + delta(x)

   ``rho`` (one per output) is fitted by least squares of ``Y_hi`` on
   ``f_lo(X_hi)`` together with a linear trend in ``x``, and ``delta`` is a
   surrogate fitted to
   ``Y_hi - rho * f_lo(X_hi)``.  Both ``f_lo`` and ``delta`` are arbitrary
   surrogate models, so the correction can be nonlinear.  With a fixed
   ``rho=1`` the low-fidelity model is assumed to be on the same scale as the
   high-fidelity one, and any scale difference has to be learned by ``delta``
   from the (few) high-fidelity points.

   Uncertainty is combined in quadrature (assuming independence):

       sigma_hi(x) = sqrt(rho^2 * sigma_lo(x)^2 + sigma_delta(x)^2)

   Note: The independence assumption is approximate because ``delta`` is
   computed using ``f_lo``.  In practice the combined std slightly
   overestimates true uncertainty — a conservative, safe approximation.

   This class assumes ``Y_lo`` and ``Y_hi`` share the same output
   dimensionality.  For heterogeneous output spaces or more than two fidelity
   levels, use ``StackedVFMSurrogate``.

   :param lo_surrogate_cls: Surrogate class for the low-fidelity model.  Defaults to
                            ``RandomForestSurrogate`` (fast, handles multi-output natively).
   :type lo_surrogate_cls: type | None
   :param hi_surrogate_cls: Surrogate class for the correction (delta) model.  Defaults to
                            ``GaussianProcessSurrogate`` — corrections are typically small and
                            smooth, making a GP a natural prior.

                            Warning: GP scales as O(n^3).  For hi-fi datasets with >500 samples,
                            prefer a sparse GP (RFFGPSurrogate, NystroemGPSurrogate) or RF.
   :type hi_surrogate_cls: type | None
   :param lo_surrogate_params: Constructor kwargs for the low-fidelity surrogate.
   :type lo_surrogate_params: dict | None
   :param hi_surrogate_params: Constructor kwargs for the correction surrogate.
   :type hi_surrogate_params: dict | None
   :param rho: Scale on the low-fidelity prediction. ``"fit"`` estimates it per output
               jointly with a linear trend, by least squares of ``Y_hi`` on
               ``[f_lo(X_hi), X_hi, 1]``, so a discrepancy that trends with ``x``
               does not bias it (on Forrester it recovers ``rho = 2``).  It falls
               back to ``"slope"`` when there are no more than ``n_features + 2``
               high-fidelity points, or when ``f_lo`` is (nearly) linear in ``X`` on
               them.  ``"slope"`` is the plain least-squares slope of ``Y_hi`` on
               ``f_lo(X_hi)`` (with an intercept, which ``delta`` absorbs), the
               estimate used before; when ``f_lo`` is constant on the high-fidelity
               inputs it is 1.  A number fixes it (``rho=1.0`` is the plain additive
               correction).  A fitted ``rho`` also multiplies the low-fidelity
               model's own error, so with a biased or strongly smoothed ``f_lo``
               (e.g. a random forest on few points) ``rho=1.0`` can predict better;
               compare both on held-out data.
   :type rho: "fit", "slope" or float, default "fit"
   :param oof_cv: Folds for out-of-fold ``f_lo`` predictions at high-fidelity inputs
                  that are also low-fidelity training points (nested designs).  The
                  full model is in-sample there, so ``rho`` and ``delta`` would be
                  fitted against predictions more accurate than at new points.  ``None``
                  or ``0`` uses the full model everywhere.
   :type oof_cv: int or None, default 5
   :param random_state: Seed for the out-of-fold split.
   :type random_state: int or None, default 0

   .. attribute:: surrogate_lo_

      Fitted low-fidelity surrogate.

      :type: surrogate

   .. attribute:: surrogate_delta_

      :type: surrogate

   .. attribute:: rho_

      :type: np.ndarray, shape (n_outputs,)

   .. attribute:: n_outputs_

      Number of outputs (must match between lo and hi data).

      >>> from multioutreg.surrogates import AdditiveCorrectionVFM
      >>> rng = np.random.default_rng(42)
      >>> X_lo = rng.standard_normal((100, 2))
      >>> Y_lo = np.sin(X_lo).sum(axis=1, keepdims=True)
      >>> X_hi = rng.standard_normal((25, 2))
      >>> Y_hi = np.sin(X_hi).sum(axis=1, keepdims=True) + 0.05 * X_hi[:, :1]
      >>> model = AdditiveCorrectionVFM()
      >>> model.fit({"lo": (X_lo, Y_lo), "hi": (X_hi, Y_hi)})
      AdditiveCorrectionVFM(...)
      >>> y_pred, y_std = model.predict(X_hi, return_std=True)
      >>> y_pred.shape
      (25, 1)

   Bases: :py:obj:`multioutreg.surrogates.conformal_mixin.ConformalMixin`


   Deep Ensemble surrogate (Lakshminarayanan et al. 2017).

   Trains ``n_estimators`` independent feed-forward networks from different
   random seeds.

   With ``loss="nll"`` (default) each network has a mean and a variance head
   and is trained on the Gaussian negative log-likelihood, as in the paper.
   The prediction is the equal-weight mixture of the members: predictive
   variance = mean of the member noise variances (aleatoric) + variance of
   the member means (epistemic).

   With ``loss="mse"`` the networks predict the mean only and the predictive
   std is the cross-network spread. That is epistemic only: it ignores the
   noise in y, so its intervals under-cover on noisy data (often far below
   nominal). Use it only for noise-free data or wrap it with conformal
   prediction.

   Requires PyTorch (core dependency)::

       pip install torch

   :param n_estimators: Number of independent networks in the ensemble.  5 gives a good
                        variance estimate; 10+ improves calibration at extra compute cost.
   :type n_estimators: int, default 5
   :param hidden_layer_sizes: Width of each hidden layer.
   :type hidden_layer_sizes: tuple[int, ...], default (128, 64)
   :param max_epochs:
   :type max_epochs: int, default 500
   :param learning_rate:
   :type learning_rate: float, default 1e-3
   :param batch_size:
   :type batch_size: int, default 64

   :type patience: int, default 30
   :param random_state: Base seed; individual networks use ``random_state + i`` so each

.. py:class:: MFKSurrogate(fidelity_levels=('lo', 'hi'), rho_regr='constant', corr='squar_exp', poly='constant', n_comp=None, eval_noise=False, propagate_uncertainty=True, n_start=10)

   Bases: :py:obj:`multioutreg.surrogates.conformal_mixin.ConformalMixin`


   Multi-fidelity co-kriging (AR1) surrogate via SMT, one model per output.

   Requires ``pip install smt``.

   :param fidelity_levels: Level names ordered from lowest to highest fidelity (at least 2).
   :type fidelity_levels: sequence of str
   :param rho_regr: Form of the scale factor ``rho(x)`` between consecutive levels.
   :type rho_regr: {"constant", "linear", "quadratic"}
   :param corr: Correlation function of each level's GP.
   :type corr: {"squar_exp", "abs_exp", "pow_exp", "matern52", "matern32"}
   :param poly: Trend of each level's GP.
   :type poly: {"constant", "linear", "quadratic"}
   :param n_comp: Use ``MFKPLS`` with this many PLS components (clamped to the number
                  of inputs). ``None`` (default) uses plain ``MFK``.
   :type n_comp: int | None
   :param eval_noise: Estimate a noise variance per level (for noisy simulators).
   :type eval_noise: bool
   :param propagate_uncertainty: Include the lower levels' variance in the predicted std (default
                                 ``True``). Without it the std counts the lower levels as exact.
   :type propagate_uncertainty: bool
   :param n_start: Optimizer restarts for the hyperparameters.
   :type n_start: int

   .. attribute:: rho_

      Fitted scale factor between each pair of consecutive levels, per
      output. Only set when ``rho_regr="constant"``.

      :type: np.ndarray, shape (n_outputs, n_levels - 1) | None
