.. py:class:: DeepEnsembleSurrogate(n_estimators: int = 5, hidden_layer_sizes: tuple = (128, 64), max_epochs: int = 500, learning_rate: float = 0.001, batch_size: int = 64, patience: int = 30, random_state: int | None = None)

   Bases: :py:obj:`multioutreg.surrogates.conformal_mixin.ConformalMixin`


   Deep Ensemble surrogate (Lakshminarayanan et al. 2017).

   Trains ``n_estimators`` independent feed-forward networks from different
   random seeds and uses their prediction disagreement as epistemic uncertainty.
   This approach consistently outperforms single-model uncertainty methods
   (MC Dropout, conformal wrappers) on calibration benchmarks.

   Each network is trained with MSE loss.  At inference the ensemble mean is
   the point estimate; predictive std is the cross-network standard deviation.

   Requires PyTorch (core dependency)::

       pip install torch

   :param n_estimators: Number of independent networks in the ensemble.  5 gives a good
                        variance estimate; 10+ improves calibration at extra compute cost.
   :type n_estimators: int, default 5
   :param hidden_layer_sizes: Width of each hidden layer.
   :type hidden_layer_sizes: tuple[int, ...], default (128, 64)
   :param max_epochs:
   :type max_epochs: int, default 500
   :param learning_rate:
   :type learning_rate: float, default 1e-3
   :param batch_size:
   :type batch_size: int, default 64
   :param patience: Early-stopping patience (epochs without improvement).
   :type patience: int, default 30
   :param random_state: Base seed; individual networks use ``random_state + i`` so each
                        gets a distinct initialisation.
   :type random_state: int | None, default None
