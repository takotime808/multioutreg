.. py:class:: MultiFidelitySurrogate(surrogate_cls, fidelity_levels: Iterable[str])

   Bases: :py:obj:`multioutreg.surrogates._clone.CloneMixin`


   Independent surrogate per fidelity level (no information transfer).

   Each level's model is fitted only on that level's data, and
   ``predict(X, level=...)`` uses only that level's model: the high-fidelity
   prediction ignores the low-fidelity data entirely.  This is a baseline
   (and a container for single-level use, e.g. in
   ``AutoDetectMultiOutputRegressor``), not a multi-fidelity model.  For
   models that use the cheaper levels to predict the expensive one, use
   ``StackedVFMSurrogate`` (any number of levels) or
   ``AdditiveCorrectionVFM`` (two levels, ``f_hi = rho * f_lo + delta``).

   ``predict`` defaults to the *last* (highest) level, the one a
   multi-fidelity study is usually after; pass ``level`` for any other.

   .. py:method:: get_params(deep: bool = True) -> dict

      Constructor arguments this surrogate was built with, by name.

      Arguments taken through ``**kwargs`` (passed on to the wrapped
      estimator) are listed individually; defaults filled in inside the
      constructor are not. ``deep`` is accepted for scikit-learn
      compatibility; nested estimator parameters are not expanded.
