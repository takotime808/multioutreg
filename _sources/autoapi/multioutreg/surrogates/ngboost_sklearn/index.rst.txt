   NGBoost surrogate providing native probabilistic uncertainty.

   Wraps ngboost.NGBRegressor in a MultiOutputRegressor and exposes
   per-output predictive standard deviations via NGBoost's natural-gradient
   distributional output.

   :param n_estimators: Number of boosting iterations.
   :type n_estimators: int, default 500
   :param learning_rate:
   :type learning_rate: float, default 0.01
   :param verbose:
   :type verbose: bool, default False
   :param \*\*kwargs: Additional keyword arguments passed to NGBRegressor.
