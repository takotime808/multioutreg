   Mixture of Experts surrogate with learned gating network.

   Specializes K expert regressors to different regions of input space
   using a gating network trained via a hard-EM loop. Each E-step reassigns
   every sample to the expert with the highest gating prior times Gaussian
   likelihood of that expert's residual, so assignments follow expert fit.

   :param n_experts:
   :type n_experts: int, default 4
   :param expert_type: Surrogate class(es) to use as experts.  A single type is used for all
                       experts; a list of types enables heterogeneous experts (one per slot).
                       Defaults to ``RandomForestSurrogate``.
   :type expert_type: type | list[type] | None
   :param expert_params: Constructor keyword arguments for each expert.  A single dict applies
                         to all experts; a list is paired element-wise with ``expert_type``.
   :type expert_params: dict | list[dict] | None
   :param gating_type:
   :type gating_type: {"linear", "mlp"}, default "linear"
   :param routing: ``"soft"``: predictions are a weighted sum over all experts.
                   ``"hard"``: each sample is routed to the highest-weight expert only.
   :type routing: {"soft", "hard"}, default "soft"
   :param max_em_iters: Maximum number of hard-EM iterations.  Stops early if assignments
                        do not change between iterations.
   :type max_em_iters: int, default 20
   :param random_state:
   :type random_state: int | None, default None

   .. py:method:: predict(X: numpy.ndarray, return_std: bool = False) -> numpy.ndarray | tuple[numpy.ndarray, numpy.ndarray]

      Predict outputs for X.

      :param X:
      :type X: np.ndarray
      :param return_std: If True, also return the mixture's predictive std. Soft routing uses
                         the law of total variance, ``sum_k w_k (sigma_k^2 + (mu_k - mu)^2)``;
                         hard routing returns the chosen expert's own std. Experts without
                         native uncertainty contribute sigma_k = 0.
      :type return_std: bool, default False

      :returns: * **y_pred** (*np.ndarray, shape (n_samples, n_outputs)*)
                * **y_std** (*np.ndarray, shape (n_samples, n_outputs)  [only if return_std=True]*)
