.. py:class:: ElasticNetSurrogate(alpha: float = 1.0, l1_ratio: float = 0.5, max_iter: int = 1000, scale_inputs: bool = True, **kwargs)

   Elastic Net regression surrogate.

   Wraps :class:`sklearn.linear_model.ElasticNet` in a ``MultiOutputRegressor``.
   Combines L1 (Lasso) and L2 (Ridge) penalties to zero out irrelevant features
   while remaining stable when inputs are correlated.  Particularly useful in the
   high-dimensional regime ``p >> n`` where purely linear baselines help isolate
   which features drive each output.

   Uncertainty is not natively returned; use :meth:`wrap_conformal` /
   :meth:`conformal_predict` for distribution-free prediction intervals.

   :param alpha: Overall regularization strength (larger → stronger shrinkage).
   :type alpha: float, default 1.0
   :param l1_ratio: Mix between L1 (``l1_ratio=1``) and L2 (``l1_ratio=0``) penalty.
                    ``l1_ratio=0.5`` balances sparsity and stability.
   :type l1_ratio: float, default 0.5
   :param max_iter: Maximum number of coordinate descent iterations.
   :type max_iter: int, default 1000
   :param scale_inputs: Standardise X first; otherwise the penalty depends on the inputs' units.
   :type scale_inputs: bool, default True
   :param \*\*kwargs: Additional keyword arguments forwarded to ``ElasticNet``.


   .. py:attribute:: alpha
      :value: 1.0



   .. py:attribute:: l1_ratio
      :value: 0.5



   .. py:attribute:: max_iter

.. py:class:: LassoSurrogate(alpha: float = 1.0, max_iter: int = 1000, scale_inputs: bool = True, **kwargs)

   Bases: :py:obj:`multioutreg.surrogates.base_sklearn.BaseSurrogate`


   Lasso (L1) regression surrogate.

   Wraps :class:`sklearn.linear_model.Lasso` in a ``MultiOutputRegressor``.
   Pure L1 penalty drives feature coefficients to exactly zero, producing a
   sparse model where only the most predictive inputs retain non-zero weights.
   Useful when interpretability and explicit feature selection matter more than
   prediction at moderate sample sizes.

   Uncertainty is not natively returned; use :meth:`wrap_conformal` /
   :meth:`conformal_predict` for distribution-free prediction intervals.

   :param alpha: L1 regularization strength.
   :type alpha: float, default 1.0
   :param max_iter: Maximum number of coordinate descent iterations.
   :type max_iter: int, default 1000
   :param scale_inputs: Standardise X first; otherwise the penalty depends on the inputs' units.
   :type scale_inputs: bool, default True
   :param \*\*kwargs: Additional keyword arguments forwarded to ``Lasso``.


   .. py:attribute:: alpha
      :value: 1.0



   .. py:attribute:: max_iter
      :value: 1000
