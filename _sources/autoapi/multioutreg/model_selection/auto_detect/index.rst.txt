.. py:function:: select_cv_strategy(n_samples: int, random_state: int | None = 0)

   Return a CV splitter appropriate for a dataset of *n_samples* rows.

   Small datasets need low-variance error estimates and cannot spare data for
   large validation folds; large datasets make many folds expensive and do
   not need them.

   - ``LeaveOneOut``                            when ``n_samples <= 20``
   - ``RepeatedKFold(n_splits=5, n_repeats=3)`` when ``20 < n_samples <= 100``
   - shuffled ``KFold(n_splits=10)``            when ``100 < n_samples <= 1000``
   - shuffled ``KFold(n_splits=5)``             when ``n_samples > 1000``


.. py:function:: resolve_cv(cv, n_samples: int, random_state: int | None = 0, scoring=None)

   Resolve a ``cv`` setting to a concrete sklearn splitter.

   :param cv: ``"auto"`` picks by dataset size via :func:`select_cv_strategy`;
              ``"loocv"`` always uses ``LeaveOneOut``; an int means a *shuffled*
              ``KFold`` with that many splits (sklearn's int default is unshuffled,
              which gives unrepresentative folds on ordered data); anything else is
              passed through ``check_cv``.
   :type cv: {"auto", "loocv"} | int | CV splitter
   :param n_samples: Number of rows the splitter will be applied to.
   :type n_samples: int
   :param random_state: Seed for shuffled / repeated splitters.
   :type random_state: int | None
   :param scoring: Scorer name. R²-type scorers are undefined on single-sample folds, so
                   ``"auto"`` falls back from ``LeaveOneOut`` to ``RepeatedKFold`` for
                   them and ``"loocv"`` raises.
   :type scoring: str | None

.. py:function:: _candidate(name: str, fold_scores, complexity: int, test_train_ratio: float | None = None, **payload) -> dict

   CV summary of one candidate with a Nadeau–Bengio corrected standard error.

   The naive SE, std/sqrt(k), assumes independent folds; K-fold training sets
   overlap, so the variance is inflated by (1/k + n_test/n_train) instead of 1/k.
   *test_train_ratio* defaults to 1/(k-1), which is exact for plain K-fold and
   leave-one-out; repeated K-fold has k = n_splits * n_repeats and must pass it.

.. py:class:: AutoDetectMultiOutputRegressor(estimators: Sequence[sklearn.base.BaseEstimator], param_spaces: Sequence[dict], cv: int | str = 'auto', scoring: str = 'neg_mean_squared_error', pre_screen: bool = False, selection: str = 'best', random_state: int | None = 0)

   Bases: :py:obj:`sklearn.base.BaseEstimator`, :py:obj:`sklearn.base.RegressorMixin`


   Fit a separate estimator per output choosing the best via grid search.

   :param estimators: Candidate sklearn estimators to evaluate.
   :type estimators: sequence of BaseEstimator
   :param param_spaces: Parameter grids corresponding to each estimator.
   :type param_spaces: sequence of dict
   :param cv: Cross-validation used to score every candidate. ``"auto"`` picks the
              scheme from the number of training rows at fit time (see
              :func:`select_cv_strategy`): leave-one-out for tiny datasets, repeated
              5-fold for small ones, 10-fold and then 5-fold as data grows.
              ``"loocv"`` forces leave-one-out, an int means a shuffled ``KFold``
              with that many splits, and any sklearn splitter is used as given.
   :type cv: {"auto", "loocv"} | int | CV splitter, default "auto"
   :param scoring: Sklearn scoring metric for GridSearchCV.
   :type scoring: str
   :param pre_screen: When True, run statistical pre-screening tests before fitting each
                      output and skip models that are either computationally expensive
                      without justification or unlikely to improve on a linear baseline.
                      See :class:`~multioutreg.model_selection.screening.ModelScreener`.
   :type pre_screen: bool, default False
   :param selection: ``"best"`` picks the highest mean CV score. ``"one_se"`` picks the
                     least complex candidate whose mean score is within one standard error
                     of the best (Nadeau–Bengio corrected, since CV folds overlap), so a
                     costly model must beat a simple one by more than CV noise.
   :type selection: {"best", "one_se"}, default "best"
   :param random_state: Seed for the shuffled / repeated splitters built from ``cv``.
   :type random_state: int | None, default 0

   .. attribute:: cv_strategy_

      The splitter ``cv`` resolved to for the training data.

      :type: CV splitter

   .. attribute:: cv_description_

      Human-readable form of ``cv_strategy_``, for reports.

      :type: str

   .. attribute:: selection_scores_

      Per output, ``{candidate: {"mean": ..., "se": ...}}`` of the CV scores
      that drove the choice. The winner's mean is optimistically biased (it
      is the max over many candidates); evaluate on a held-out test set for
      an unbiased estimate.

      :type: list of dict
