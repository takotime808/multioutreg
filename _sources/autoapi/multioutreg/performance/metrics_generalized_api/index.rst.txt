.. py:function:: get_uq_performance_metrics_flexible(model: Any, X_test: numpy.ndarray, y_test: numpy.ndarray, uncertainty_method: Optional[str] = None, y_pred_std: Optional[numpy.ndarray] = None, std_is_var: bool = False) -> Tuple[pandas.DataFrame, Dict[str, float]]

   Computes UQ metrics for any model: handles different APIs for uncertainty prediction.

   :param model: Your trained regressor (must implement predict and, optionally, predict_std or predict_var).
   :param X_test: Test features, shape (n_samples, n_features).
   :param y_test: Test targets, shape (n_samples, n_outputs).
   :param uncertainty_method: Optional string, one of:
                              ['return_std', 'return_cov', 'predict_std', 'predict_var']
   :param y_pred_std: Optional (n_samples, n_outputs) ndarray, directly supply stddevs or variances.
   :param std_is_var: If True, will sqrt the std array passed in (for variance-to-std conversion).

   :returns: pd.DataFrame with metrics per output.
             overall_metrics: dict of metrics computed on all outputs at once (flattened),
                 after dividing each output by the std of its ``y_test`` column, so
                 rmse/mae/nll are in standard-deviation units rather than mixed units.
   :rtype: metrics_df
