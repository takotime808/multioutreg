.. py:class:: SplitConformalPredictor(estimator, calibration_size: float = 0.2, adaptive: bool = False, random_state: Optional[int] = None)

   Bases: :py:obj:`multioutreg.conformal.base.BaseConformalPredictor`


   Split (inductive) conformal prediction.

   Splits training data into a proper training set and a calibration set.
   The model is fitted on the training set, and nonconformity scores
   (absolute residuals) are computed on the calibration set. At prediction
   time, the conformal quantile of these scores determines the interval width.

   Coverage guarantee: P(Y in [y_lower, y_upper]) >= 1 - alpha
   for exchangeable data.

   :param estimator: Any regressor with fit/predict. Will be cloned internally.
   :type estimator: sklearn-compatible regressor
   :param calibration_size: Fraction of training data reserved for calibration (default 0.2).
   :type calibration_size: float
   :param adaptive: If True, uses normalized residuals |y - y_hat| / y_std for
                    locally-adaptive intervals. Requires the estimator to support
                    predict(X, return_std=True).
   :type adaptive: bool
   :param random_state: Seed for reproducible calibration splits.
   :type random_state: int, optional


   .. py:attribute:: calibration_size
      :value: 0.2



   .. py:attribute:: adaptive
      :value: False

.. py:class:: CVPlusConformalPredictor(estimator, n_folds: int = 5, random_state: Optional[int] = None)

   Bases: :py:obj:`multioutreg.conformal.base.BaseConformalPredictor`


   CV+ conformal prediction (Barber et al., 2021).

   Uses K-fold cross-validation to compute out-of-fold residuals R_i for every
   training point, avoiding the data-splitting inefficiency of split conformal.
   All data is used for both training and calibration.

   For a test point x, with mu_{-k(i)} the model fitted without the fold
   containing training point i, the interval is::

       lower = floor(alpha (n+1))-th smallest of { mu_{-k(i)}(x) - R_i }
       upper = ceil((1-alpha)(n+1))-th smallest of { mu_{-k(i)}(x) + R_i }

   Coverage guarantee: P(Y in interval) >= 1 - 2*alpha for exchangeable data
   (in practice usually close to 1 - alpha). Intervals are unbounded when n is
   too small for the requested alpha.

   :param estimator: Any regressor with fit/predict. Cloned (or deep-copied) for each fold.
   :type estimator: sklearn-compatible regressor
   :param n_folds: Number of cross-validation folds (default 5).
   :type n_folds: int
   :param random_state: Seed for reproducible fold splits.
   :type random_state: int, optional


   .. py:attribute:: n_folds
      :value: 5

.. py:class:: JointConformalPredictor(estimator, score: str = 'max', calibration_size: float = 0.2, shape_size: float = 0.5, adaptive: bool = False, ridge: float = 1e-06, random_state: Optional[int] = None)

   Bases: :py:obj:`multioutreg.conformal.base.BaseConformalPredictor`


   Split conformal regions with simultaneous coverage across outputs.

   Coverage guarantee: P(the whole output vector lies in the region)
   >= 1 - alpha for exchangeable data.

   :param estimator: Any regressor with fit/predict. Cloned (or deep-copied) internally.
   :type estimator: regressor
   :param score: Nonconformity score, and so the shape of the region (see module
                 docstring). Default ``"max"``.
   :type score: {"max", "mahalanobis", "bonferroni"}
   :param calibration_size: Fraction of the data held out from model fitting (default 0.2).
   :type calibration_size: float
   :param shape_size: Fraction of the held-out rows used to estimate the per-output scales
                      or the residual covariance; the rest set the conformal quantile.
                      ``0`` estimates the shape from training residuals. Ignored for
                      ``"bonferroni"``. Default 0.5.
   :type shape_size: float
   :param adaptive: If True, residuals are divided by the model's ``return_std`` before
                    scoring, so the region grows and shrinks with the model's own
                    uncertainty.
   :type adaptive: bool
   :param ridge: Added to the covariance diagonal, relative to its mean variance, so
                 a singular covariance (outputs that are exact functions of each
                 other) can still be inverted. Default 1e-6.
   :type ridge: float
   :param random_state: Seed for the calibration and shape splits.
   :type random_state: int, optional


   .. py:attribute:: score
      :value: 'max'



   .. py:attribute:: calibration_size
      :value: 0.2



   .. py:attribute:: shape_size
      :value: 0.5



   .. py:attribute:: adaptive
      :value: False



   .. py:attribute:: ridge
      :value: 1e-06

   .. py:method:: predict_interval(X: numpy.ndarray, alpha: float = 0.1) -> Tuple[numpy.ndarray, numpy.ndarray]

      Simultaneous intervals: all outputs covered together with prob >= 1-alpha.

      For ``"max"`` and ``"bonferroni"`` these bounds are the region itself.
      For ``"mahalanobis"`` they are the ellipsoid's bounding box, which is
      valid but larger than the ellipsoid; use :meth:`contains` and
      :meth:`log_volume` to work with the ellipsoid directly.

      :returns: **y_lower, y_upper** -- Shape (n_samples,) for single output or (n_samples, n_outputs).
      :rtype: np.ndarray

.. py:function:: joint_coverage(y_true: numpy.ndarray, y_lower: numpy.ndarray, y_upper: numpy.ndarray) -> float

   Fraction of rows whose outputs are *all* inside their intervals.

   Per-output coverage from :func:`conformal_coverage` can meet its target
   on every output while the outputs are covered together far less often.
   Compare this against ``1 - alpha`` for intervals meant to hold jointly,
   such as those from ``JointConformalPredictor``.

   :param y_true:
   :type y_true: (n_samples,) or (n_samples, n_outputs)
   :param y_lower:
   :type y_lower: same shape as y_true
   :param y_upper:
   :type y_upper: same shape as y_true
