.. py:class:: ActiveLearner(model_factory: Callable, bounds, acquisition: Union[str, Callable] = 'max_variance', acquisition_kwargs: Optional[dict] = None, weights=None, minimize: bool = True, batch_size: int = 1, n_candidates: int = 1024, length_scale: Optional[float] = None, penalize_train: bool = False, allow_zero_std: bool = False, random_state: Optional[int] = 0)

   Sequential design for a multi-output surrogate on a box-shaped domain.

   :param model_factory: Zero-argument callable returning an unfitted surrogate with
                         ``fit(X, Y)`` and ``predict(X, return_std=True)``. The model is refit
                         from scratch after every :meth:`tell`.
   :type model_factory: callable
   :param bounds:
   :type bounds: array-like, shape (n_features, 2)
   :param acquisition: One of ``"max_variance"``, ``"ucb"``, ``"ei"``, ``"pi"``, ``"random"``,
                       or ``f(mean, std, **kwargs) -> scores``.
   :type acquisition: str or callable, default "max_variance"
   :param acquisition_kwargs: Extra arguments for the acquisition (``beta``, ``xi``, ``how``).
   :type acquisition_kwargs: dict, optional
   :param weights: Per-output weights: aggregation weights for ``max_variance``,
                   scalarization weights for ``ucb`` / ``ei`` / ``pi``.
   :type weights: sequence of float, optional
   :param minimize: Direction for the optimization acquisitions.
   :type minimize: bool, default True
   :param batch_size:
   :type batch_size: int, default 1
   :param n_candidates: Size of the fresh Sobol candidate pool drawn on every :meth:`ask`.
   :type n_candidates: int, default 1024
   :param length_scale: Passed to :func:`multioutreg.active.batch.select_batch`.
   :param penalize_train: Passed to :func:`multioutreg.active.batch.select_batch`.
   :param allow_zero_std: See :func:`multioutreg.active.acquisition.predict_mean_std`.
   :type allow_zero_std: bool, default False
   :param random_state:
   :type random_state: int or None, default 0

      Run the loop with a Python ``simulator(X) -> Y``.

      Stops after ``n_iter`` batches, when ``max_evals`` evaluations are
      reached, or (with ``rtol`` and test data) when held-out NRMSE has not
      improved by a relative ``rtol`` for ``patience`` iterations.

      :returns: :attr:`history_`, one record per fitted model.
      :rtype: list of dict
