.. py:class:: CommitteeSurrogate(model_factory: Callable, n_members: int = 5, random_state=0)

   Query-by-committee uncertainty for any surrogate.

   Fits ``n_members`` copies of ``model_factory()`` on bootstrap resamples and
   predicts the member mean, with the spread across members as ``std``. This
   lets models without native uncertainty (KNN, linear, plain trees) take part
   in variance-based active learning (Burbidge et al. 2007).

   :param model_factory: Zero-argument callable returning an unfitted surrogate with
                         ``fit(X, Y)`` and ``predict(X)``.
   :type model_factory: callable
   :param n_members:
   :type n_members: int, default 5
   :param random_state:
   :type random_state: int or None, default 0

.. py:function:: predict_mean_std(model, X, allow_zero_std: bool = False, **predict_kwargs)

   Return ``(mean, std)`` as 2-D arrays, refusing silent zero uncertainty.

   ``BaseSurrogate`` and ``AutoDetectMultiOutputRegressor`` fill ``std`` with
   zeros for outputs whose model has no native uncertainty. A variance-based
   acquisition would read that as "perfectly known" and never sample for that
   output, so this raises unless ``allow_zero_std`` is set.

.. py:function:: upper_confidence_bound(mean, std, beta: float = 4.0, weights=None, minimize: bool = True) -> numpy.ndarray

   GP-UCB (Srinivas et al. 2010) on the scalarized objective.

   With ``minimize=True`` this is the negated lower confidence bound, so that
   larger is still better.


.. py:function:: select_batch(U_cand: numpy.ndarray, scores: numpy.ndarray, batch_size: int, U_train: Optional[numpy.ndarray] = None, length_scale: Optional[float] = None, penalize_train: bool = False) -> numpy.ndarray

   Greedy top-k with a Gaussian distance penalty around picked points.

   After each pick, every candidate's score is multiplied by
   ``1 - exp(-d^2 / (2 l^2))`` with ``d`` its distance to the pick, so a batch
   spreads across the acquisition surface instead of clustering on one peak
   (local penalization, González et al. 2016).

   :param U_cand: Candidates in the unit cube (distances are measured there).
   :type U_cand: array, shape (n_candidates, n_features)
   :param scores: Acquisition values; larger is better. Shifted to be non-negative.
   :type scores: array, shape (n_candidates,)
   :param batch_size:
   :type batch_size: int
   :param U_train: Existing design in the unit cube; sets the default length scale and,
                   with ``penalize_train``, is penalized like a pick.
   :type U_train: array, optional
   :param length_scale: Defaults to :func:`default_length_scale` of ``n_train + batch_size``.
   :type length_scale: float, optional

   :returns: Indices into ``U_cand``.
   :rtype: np.ndarray of int, shape (batch_size,)

.. py:function:: get_benchmark(name: str, cost_ratio: float = 10.0, n_features: Optional[int] = None) -> Benchmark

   Return a :class:`Benchmark` by name.

   Multi-fidelity benchmarks have levels ``"lo"`` and ``"hi"`` with costs
   ``1`` and ``cost_ratio``. ``n_features`` sets the input dimension of the
   scalable ZDT problems (default 6; the literature uses 30, which needs far
   more training points) and of DTLZ2 (default 7, three objectives); the
   other benchmarks have a fixed dimension.

.. py:function:: fidelity_info(model, X, levels: Sequence[str], nested: bool = True, trust: Optional[Dict[str, numpy.ndarray]] = None) -> FidelityInfo

   Per-level variance reduction for the high-fidelity prediction at ``X``.

   For AR1 models (``AdditiveCorrectionVFM``),
   ``var_hi = rho^2 var_lo + var_delta``: a low-fidelity run removes the first
   term; a high-fidelity run removes ``var_delta``, plus the first term when
   ``nested`` (the low fidelity is run at the same point too).

   For other models with ``predict(X, level=..., return_std=True)`` the
   reduction is ``corr_l^2 var_hi``, with ``corr_l`` the correlation of level
   ``l`` and high-fidelity predictions over ``X`` (Huang et al. 2006).

   ``trust`` (see :func:`level_trust`) multiplies each lower level's
   reduction, and its square root that level's correlation.


.. py:function:: level_trust(model, levels: Sequence[str], X_hi, Y_hi, z: float = 1.0, min_points: int = 6) -> Dict[str, numpy.ndarray]

   How far the high-fidelity data supports each lower level, per output, in [0, 1].

   The squared lower confidence bound (Fisher z, ``z`` standard errors) of
   ``|corr(level prediction, Y_hi)|`` at the high-fidelity points. It is 0
   until there are ``min_points`` high-fidelity points (with 4 points, pure
   noise reaches ``|r| > 0.95`` a few percent of the time), so a lower level earns
   credit only once the data shows it predicts the high fidelity. Without it,
   a scale such as AR1's ``rho`` fitted to a handful of points can make an
   uninformative level look valuable indefinitely.
