.. py:function:: plot_multioutput_shap_bar_subplots(model: sklearn.multioutput.MultiOutputRegressor, X: numpy.ndarray, feature_names: Optional[Sequence[str]] = None, output_names: Optional[Sequence[str]] = None, max_cols: int = 3, savefig: Optional[str] = None) -> matplotlib.pyplot.Figure

   Plot mean absolute SHAP value bar plots for each output of a MultiOutputRegressor in subplots.
   The figure always uses at most `max_cols` columns per row (default 3), and shows the SHAP value next to each bar.

   :param model: A fitted MultiOutputRegressor model (e.g., wrapping RandomForestRegressor).
   :type model: MultiOutputRegressor
   :param X: Feature matrix of shape (n_samples, n_features) used for SHAP analysis.
   :type X: np.ndarray
   :param feature_names: List of feature names (length n_features). If None, will use "feature_0", ... etc.
   :type feature_names: sequence of str, optional
   :param output_names: List of output/target names (length n_outputs). If None, will use "Output 0", ... etc.
   :type output_names: sequence of str, optional
   :param max_cols: Maximum number of columns per row in the subplot grid.
   :type max_cols: int, default=3
   :param savefig: If given, path to save the figure to disk instead of showing.
   :type savefig: str or None, default=None

   :returns: **fig** -- The matplotlib Figure containing all subplots.
   :rtype: matplotlib.figure.Figure

   .. admonition:: Example

      >>> plot_multioutput_shap_bar_subplots(regr, X, feature_names=feature_names, output_names=output_names)


.. py:function:: generate_shap_plot(model: Any, X: numpy.ndarray, output_names: List[str], feature_names: Optional[Sequence[str]] = None, max_rows: int = 200, background_size: int = 10, random_state: int = 0) -> Dict[str, str]

   Generate SHAP summary plots for each output dimension.

   Explains up to ``max_rows`` rows of ``X`` against a k-means summary of
   ``X`` with ``background_size`` centres. The cost of SHAP's explainers grows
   with the background size; on Friedman 1 (10 inputs, 100 rows, a GP) the
   full-data background took 37 s and the k-means one 3 s, with the same
   feature ranking.

   :param model: Multi-output model.  May expose ``estimators_`` (one per output) or
                 may be a joint multi-output model (e.g. MixtureOfExpertsSurrogate).
   :type model: Any
   :param X: Input features used to compute SHAP values.
   :type X: np.ndarray
   :param output_names: Names of output dimensions.
   :type output_names: List[str]
   :param feature_names: Names of the input features; defaults to SHAP's "Feature i" labels.
   :type feature_names: Sequence[str], optional
   :param max_rows: Rows of ``X`` explained and plotted; a random subset beyond that.
   :type max_rows: int, default 200
   :param background_size: Number of k-means centres used as the SHAP background.
   :type background_size: int, default 10
   :param random_state: Seed for the row subset.
   :type random_state: int, default 0

   :returns: Dictionary mapping output names to base64-encoded SHAP plots.
   :rtype: Dict[str, str]

.. py:function:: shap_importance_table(model: Any, X: numpy.ndarray, output_names: List[str], feature_names: Sequence[str], max_rows: int = 100, background_rows: int = 50, random_state: int = 0) -> Dict[str, Dict[str, float]]

   Mean absolute SHAP value per feature for each output, as numbers.

   Explains up to ``max_rows`` rows of ``X`` against a background sample of
   ``background_rows``. Per-output estimators in ``model.estimators_`` get a
   fast ``TreeExplainer`` when they support it; anything else uses SHAP's
   model-agnostic explainer on column ``i`` of ``model.predict``.

   Returns ``{output: {feature: mean_abs_shap}}``. Raises if SHAP fails for
   every output.
