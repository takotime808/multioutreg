.. py:function:: plot_intervals_ordered(y_pred: numpy.ndarray, y_std: numpy.ndarray, y_true: numpy.ndarray, n_subset: Optional[int] = None, ylims: Optional[Tuple[float, float]] = None, num_stds_confidence_bound: float = 2, ax: Optional[matplotlib.pyplot.Axes] = None, add_legend: bool = True) -> Tuple[matplotlib.pyplot.Line2D, matplotlib.pyplot.Line2D, matplotlib.pyplot.Axes]

   Plot ordered predicted values and intervals for a single target.

   :param y_pred: Predicted values, shape (n_samples,).
   :type y_pred: np.ndarray
   :param y_std: Predicted standard deviations, shape (n_samples,).
   :type y_std: np.ndarray
   :param y_true: Observed/true values, shape (n_samples,).
   :type y_true: np.ndarray
   :param n_subset: If provided, subsample n_subset random points.
   :type n_subset: int, optional
   :param ylims: Y-axis limits as (ymin, ymax).
   :type ylims: tuple of float, optional
   :param num_stds_confidence_bound: Number of standard deviations for error bars. Default is 2.
   :type num_stds_confidence_bound: float, optional
   :param ax: Matplotlib axes to plot on. If None, a new one is created.
   :type ax: plt.Axes, optional
   :param add_legend: Whether to add a legend to the plot.
   :type add_legend: bool, optional

   :returns: * **pred_line** (*plt.Line2D*) -- The line artist for the predicted values.
             * **obs_line** (*plt.Line2D*) -- The line artist for the observed values.
             * **ax** (*plt.Axes*) -- The matplotlib axes containing the plot.

   Plot predicted values with confidence intervals and error bars.

   Handles single and multi-output regression, with error bars on predictions.

   :param y_true: Ground truth values, shape (n_samples, n_outputs) or (n_samples,).
   :type y_true: np.ndarray or list of float
   :param preds: Predicted mean values, shape (n_samples, n_outputs) or (n_samples,).
   :type preds: np.ndarray or list of float
   :param std: Predicted standard deviations, shape (n_samples, n_outputs) or (n_samples,).
   :type std: np.ndarray or list of float
   :param output_names: Names for output variables. Default is ["Output 0", ...].
   :type output_names: list of str, optional
   :param n_cols: Number of subplot columns for multi-output. Default is 3.
   :type n_cols: int, optional
   :param alpha: Significance level for confidence interval (default 0.05 for 95% CI).
   :type alpha: float, optional
   :param plot_errorbars: Option to include errorbars.
   :type plot_errorbars: bool, optional
   :param plot_ci_band: Option to include confidence interval.
   :type plot_ci_band: bool, optional
   :param savefig: Path to save figure. If None, the figure is shown. Default is None.
   :type savefig: str or None, optional

   :rtype: None
