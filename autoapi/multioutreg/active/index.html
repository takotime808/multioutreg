class CommitteeSurrogate(model_factory: Callable, n_members: int = 5, random_state=0)[source]¶

Query-by-committee uncertainty for any surrogate.

Fits n_members copies of model_factory() on bootstrap resamples and predicts the member mean, with the spread across members as std. This lets models without native uncertainty (KNN, linear, plain trees) take part in variance-based active learning (Burbidge et al. 2007).

Parameters:

  • model_factory (callable) – Zero-argument callable returning an unfitted surrogate with fit(X, Y) and predict(X).

  • n_members (int, default 5)

  • random_state (int or None, default 0)

predict_mean_std(model, X, allow_zero_std: bool = False, **predict_kwargs)[source]¶

Return (mean, std) as 2-D arrays, refusing silent zero uncertainty.

BaseSurrogate and AutoDetectMultiOutputRegressor fill std with zeros for outputs whose model has no native uncertainty. A variance-based acquisition would read that as “perfectly known” and never sample for that output, so this raises unless allow_zero_std is set.

select_batch(U_cand: numpy.ndarray, scores: numpy.ndarray, batch_size: int, U_train: numpy.ndarray | None = None, length_scale: float | None = None, penalize_train: bool = False) → numpy.ndarray[source]¶

Greedy top-k with a Gaussian distance penalty around picked points.

After each pick, every candidate’s score is multiplied by 1 - exp(-d^2 / (2 l^2)) with d its distance to the pick, so a batch spreads across the acquisition surface instead of clustering on one peak (local penalization, González et al. 2016).

Parameters:

  • U_cand (array, shape (n_candidates, n_features)) – Candidates in the unit cube (distances are measured there).

  • scores (array, shape (n_candidates,)) – Acquisition values; larger is better. Shifted to be non-negative.

  • batch_size (int)

  • U_train (array, optional) – Existing design in the unit cube; sets the default length scale and, with penalize_train, is penalized like a pick.

  • length_scale (float, optional) – Defaults to default_length_scale of n_train + batch_size.

Returns:

Indices into U_cand.

Return type:

np.ndarray of int, shape (batch_size,)

class MultiFidelityActiveLearner(model_factory: Callable, bounds, levels: Sequence[str], costs: Dict[str, float], acquisition: str = 'variance', nested: bool = True, min_hi_fraction: float = 0.25, trust_z: float | None = 1.0, how: str = 'sum', weights=None, minimize: bool = True, xi: float = 0.0, n_candidates: int = 1024, random_state: int | None = 0)[source]¶

Choose the next (x, level) to run under a total cost budget.

Parameters:

  • model_factory (callable) – Zero-argument callable returning an unfitted multi-fidelity surrogate with fit({level: (X, Y)}), e.g. AdditiveCorrectionVFM (two levels named "lo" / "hi") or StackedVFMSurrogate.

  • bounds (array-like, shape (n_features, 2))

  • levels (sequence of str) – Fidelity levels, cheapest first; the last one is the target.

  • costs (dict[level, float]) – Cost of one evaluation at each level.

  • acquisition ({"variance", "ei"}, default "variance") – "variance": variance reduction per cost (global accuracy). "ei": multi-fidelity expected improvement (optimization).

  • nested (bool, default True) – A query at a level also runs every lower level at the same point.

  • min_hi_fraction (float, default 0.25) – Force a high-fidelity query whenever high-fidelity spending is below this share of the total spent. Evidence about whether a lower level is informative only comes from high-fidelity runs, so this keeps it coming even when a lower level (spuriously) looks valuable.

  • trust_z (float or None, default 1.0) – Standard errors for level_trust; lower levels are credited only as far as the high-fidelity data shows they predict it. None trusts the model’s own variance split.

fidelity_info(model, X, levels: Sequence[str], nested: bool = True, trust: Dict[str, numpy.ndarray] | None = None) → FidelityInfo[source]¶

Per-level variance reduction for the high-fidelity prediction at X.

For AR1 models (AdditiveCorrectionVFM), var_hi = rho^2 var_lo + var_delta: a low-fidelity run removes the first term; a high-fidelity run removes var_delta, plus the first term when nested (the low fidelity is run at the same point too).

For other models with predict(X, level=..., return_std=True) the reduction is corr_l^2 var_hi, with corr_l the correlation of level l and high-fidelity predictions over X (Huang et al. 2006).

trust (see level_trust) multiplies each lower level’s reduction, and its square root that level’s correlation.

level_trust(model, levels: Sequence[str], X_hi, Y_hi, z: float = 1.0, min_points: int = 6) → Dict[str, numpy.ndarray][source]¶

How far the high-fidelity data supports each lower level, per output, in [0, 1].

The squared lower confidence bound (Fisher z, z standard errors) of |corr(level prediction, Y_hi)| at the high-fidelity points. It is 0 until there are min_points high-fidelity points (with 4 points, pure noise reaches |r| > 0.95 a few percent of the time), so a lower level earns credit only once the data shows it predicts the high fidelity. Without it, a scale such as AR1’s rho fitted to a handful of points can make an uninformative level look valuable indefinitely.
