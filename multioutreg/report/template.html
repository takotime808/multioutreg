Conformal Prediction Intervals

Conformal prediction provides distribution-free prediction intervals with finite-sample coverage guarantees. Unlike Gaussian confidence intervals, conformal intervals make no assumptions about error distributions and contain the true value with at least the specified probability on average (marginal coverage), provided calibration and test data are exchangeable.
