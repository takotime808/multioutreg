Notes¶

Multi-Output Strategies in Detail¶

Per-output (MultiOutputRegressor) — BaseSurrogate.__init__ wraps the sklearn estimator in sklearn.multioutput.MultiOutputRegressor. One clone is fit independently per output column. Output covariances are not modeled.

Per-output (internal estimator list) — Surrogates that maintain their own self.estimators_ list: RFFGPSurrogate, NystroemGPSurrogate, GPXSurrogate, KPLSSurrogate, ARDGPSurrogate. They inherit from ConformalMixin rather than BaseSurrogate and manually stack per-column predictions. Functionally equivalent to MultiOutputRegressor but necessary when the underlying API (e.g. SMT) does not conform to the sklearn estimator interface, or when per-output hyperparameters (e.g. per-output random seeds) are required.

Kernel hyperparameters for the GP-family surrogates (length scale, amplitude, noise, ARD, and the grids the model search tries) are covered in Surrogate Hyperparameters.

PolynomialBayesianRidgeSurrogate inherits from BaseSurrogate (and therefore uses MultiOutputRegressor internally), but overrides predict to iterate model.estimators_ directly when return_std=True in order to collect per-output posterior standard deviations.

Joint (_multi_output = True) — BNNSurrogate, DeepEnsembleSurrogate, MixtureOfExpertsSurrogate, StackedVFMSurrogate, and AdditiveCorrectionVFM predict all outputs simultaneously from a shared architecture (or composition). Inter-output correlations can be captured. These cannot be wrapped in MultiOutputRegressor and are not included in the standard AutoDetect grid search (they require a separate evaluation path via register_multi_output_candidates).

CatBoost point predictions¶

With the default use_uncertainty=True, CatBoost trains with RMSEWithUncertainty, and the raw CatBoostRegressor.predict returns [mean, variance] per row. CatBoostSurrogate.predict(X) and _conformal_point_predict return only the mean column, shape (n_samples, n_outputs).

Statistical Pre-Screening Gates (pre_screen=True)¶

When AutoDetectMultiOutputRegressor(..., pre_screen=True) (or with_vendored_surrogates(pre_screen=True)) is used, ModelScreener runs inexpensive statistical tests before fitting and gates expensive or unlikely-to-help models per output column. With a custom estimator list, the rule for each estimator is looked up from its class name; estimators with no rule are always tried (with a warning).

Normality is tested on OLS residuals. Breusch–Pagan only runs when RESET passes (with a non-linear mean it cannot separate variance from misfit); otherwise it is reported as not tested and the heteroscedasticity-gated models stay eligible. The normality, RESET and Breusch–Pagan p-values of all outputs are corrected jointly (Holm by default; ModelScreener(correction="bh") for Benjamini–Hochberg, None to disable).

Time Series Forecasters (multioutreg.time_series)¶

These classes share a common fit(y) → predict(prediction_length, quantiles) → ForecastResult contract. ForecastResult.quantiles has shape [n_series, n_quantiles, horizon]. They are not surrogate models and are not part of the regression grid search.
