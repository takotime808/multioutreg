References¶

Published work behind multioutreg: the methods the code implements today, and the methods needed for the items in the Expanding the Surrogate Offerings. Each table row gives the citation, a link, and a note naming the module the reference applies to and what to check there.

IDs are a section prefix plus a number (e.g. GP3, AL7). Multi-fidelity references use FID so they are not confused with the MF items in the audit checklist.

Every DOI and arXiv link was checked to resolve to the cited paper (October 2026).

Where to Start¶

Checks on existing code

  • Auto-Detect reports the CV score of the best model per output, which is optimistically biased (MS2).

  • forest_uncertainty adds a noise term that does not vary with x (TR3, TR4).

  • bnn_pytorch MC Dropout variance has no model-precision (τ⁻¹) term (NN2).

  • quantile_sklearn converts quantiles to a symmetric pseudo-std (TR10, CP5).

  • Reports and GUI labels should quote the same 1 − 2α CV+ guarantee as the cv_plus docstrings (CP4).

Roadmap “Recommended First Batch”

  1. MFKSurrogate: FID1, FID2, FID4, GP7.

  2. PCA output reduction: MO3, VZ3.

  3. Multi-task GP: MO1, MO2, GP5.

  4. Gaussian copula and joint metrics: MO10, JM1, JM2, UQ1.

Methods that multioutreg implements today, grouped by package.
