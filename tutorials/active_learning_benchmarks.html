Active Learning on Benchmark Functions¶

This tutorial shows the multioutreg.active prototype on analytic benchmark functions, where the true response is known everywhere, so every surrogate can be scored on a large held-out set. The design behind it is on the Active Learning Plan page.

What this tutorial covers:

  1. Benchmarks: the analytic test problems, including multi-fidelity pairs

  2. Watching the loop: one-dimensional max-variance sampling, step by step

  3. From a few runs to the true curve: the GP and its confidence band as each run is added, and the cost of active vs passive designs to replicate the true curve

  4. Active vs passive designs: held-out error against random and Sobol designs

  5. Multi-output standardization: why output stds must be standardized

  6. Batch selection: top-k vs distance-penalized batches

  7. Optimization: expected improvement and UCB

  8. Query-by-committee: active learning for a model with no native uncertainty

  9. Multi-fidelity active learning: choosing the point and the fidelity level under a cost budget

  10. Summary

Every experiment repeats over a few seeds and reports the median (line) and the range (band). The seed counts and budgets are small so the notebook runs in a few minutes; the conclusions are indicative, not a benchmark study.

    "ytick.color": MUTED, "lines.linewidth": 2, "legend.frameon": False, "font.size": 9,

    "figure.titlesize": 11,

SEEDS = range(3)


def gp():
    # Matern-5/2 GP with a length-scale floor and a few optimizer restarts. sklearn's
    # optimizer otherwise falls into a "short length scale + noise" optimum on small
    # designs (seen on Forrester with ~10 points), which ruins any variance-based acquisition.
    kernel = (ConstantKernel(1.0) * Matern(1.0, length_scale_bounds=(0.1, 100.0), nu=2.5)
              + WhiteKernel(1e-6, (1e-10, 1e-2)))
    return GaussianProcessSurrogate(kernel=kernel, n_restarts_optimizer=2, random_state=0)


def band(ax, x, runs, color, label):
    # Median line plus min-max band over seeds; runs has shape (n_seeds, len(x)).
    runs = np.asarray(runs)
    ax.fill_between(x, runs.min(0), runs.max(0), color=color, alpha=0.15, lw=0)
    ax.plot(x, np.median(runs, 0), color=color, label=label)


def passive(bench, n, method, seed, Xt, Yt, model=gp):
    X = bench.sample(n, method=method, seed=seed)
    return heldout_metrics(model().fit(X, bench(X)), Xt, Yt)["nrmse"]

## 2. Watching the loop

ActiveLearner takes a model factory and box bounds. Each ask() draws a fresh Sobol candidate pool, scores it with the acquisition and returns the best point(s); tell() adds the evaluated points. run() chains the two for a Python simulator.

Below, the max-variance acquisition (the GP’s predictive variance, standardized by the output’s spread) starts from 3 points on Forrester. Each new point goes where the model is least certain, so the design fills in the domain, and the region around the minimum is resolved because the function’s curvature keeps the variance high there.

[4]:

## 3. From a few runs to the true curve: what each design costs

Treat the high-fidelity Forrester function as an expensive simulator: each run costs 10 units. The goal is to start from a tiny design (3 runs) and add runs one at a time until the GP reproduces the true curve, here meaning held-out NRMSE of 1% or less on a dense grid (at that level the fitted and true curves are indistinguishable on the plot). The fewer runs that takes, the cheaper the study.

Every design below adds one run at a time, and each run’s points are a prefix of the next run’s:

  • active (max variance): the next run goes where the current GP is least certain;

  • Sobol sequence: the next point of a scrambled Sobol sequence, a strong space-filling design;

  • random: the next i.i.d. uniform point.

The animation refits each design’s GP after every new run. The band is the GP’s ±2σ interval, the ringed point is the newest run, and the lower panel tracks each design’s error against the cumulative cost.

[5]:

import base64
import tempfile

from IPython.display import HTML
from matplotlib.animation import FuncAnimation, PillowWriter
from scipy.stats import qmc

b = get_benchmark("forrester")
C_HI = b.costs["hi"]                      # cost of one high-fidelity run
x = np.linspace(0, 1, 400)[:, None]       # dense grid: the "true curve" to replicate
y = b(x)
N0, TOL = 3, 0.01                         # start from 3 runs; target NRMSE of 1%
METHODS = {"active": ("Active (max variance)", BLUE),
           "sobol": ("Sobol sequence", AQUA),
           "random": ("Random", ORANGE)}


def nested_designs(seed, n_max):
    # Point sequences in the order they are run, so the first n points are the n-run design.
    al = ActiveLearner(gp, b.bounds, acquisition="max_variance", random_state=seed)
    al.run(b, n_init=N0, n_iter=n_max - N0)
    lo, width = b.bounds[:, 0], np.diff(b.bounds, axis=1).ravel()
    return {"active": al.X_,
            "sobol": lo + width * qmc.Sobol(b.n_features, scramble=True, seed=seed).random(n_max),
            "random": lo + width * np.random.default_rng(seed).uniform(size=(n_max, b.n_features))}


def fit_on(X):
    return gp().fit(X, b(X))


# Animate one seed: refit every design after each new run.
N_ANIM = 20
frames = list(range(N0, N_ANIM + 1))
anim_designs = nested_designs(0, N_ANIM)
snap = {k: [] for k in METHODS}
for k, X in anim_designs.items():
    for n in frames:
        model = fit_on(X[:n])
        mean, std = model.predict(x, return_std=True)
        snap[k].append((mean.ravel(), std.ravel(), heldout_metrics(model, x, y)["nrmse"]))

fig = plt.figure(figsize=(11, 5.4))
gs = fig.add_gridspec(2, 3, height_ratios=[1.5, 1], hspace=0.45, wspace=0.18)
tops = [fig.add_subplot(gs[0, i]) for i in range(3)]
err_ax = fig.add_subplot(gs[1, :])
y_lim = (y.min() - 6, y.max() + 6)


def draw(i):
    n = frames[i]
    for ax, (k, (label, color)) in zip(tops, METHODS.items()):
        mean, std, e = snap[k][i]
        X = anim_designs[k][:n]
        ax.clear()
        ax.plot(x, y, color=MUTED, lw=1.2, ls="--", label="true curve")
        ax.fill_between(x.ravel(), mean - 2 * std, mean + 2 * std, color=color, alpha=0.2, lw=0, label="±2σ")
        ax.plot(x, mean, color=color, label="GP mean")
        ax.scatter(X[:-1, 0], b(X[:-1]).ravel(), color=INK, s=16, zorder=3)
        ax.scatter(X[-1:, 0], b(X[-1:]).ravel(), s=70, facecolor="none", edgecolor=INK, linewidth=1.5, zorder=4)
        ax.set(ylim=y_lim, xlabel="x", title=label)
        ax.text(0.03, 0.95, f"NRMSE {e:.1%}" + ("  ✓ target" if e <= TOL else ""),
                transform=ax.transAxes, va="top", fontsize=8, color=INK)
    tops[0].set_ylabel("f(x)")
    tops[0].legend(loc="lower left", fontsize=7)
    err_ax.clear()
    for k, (label, color) in METHODS.items():
        err = [s[2] for s in snap[k][: i + 1]]
        err_ax.plot(np.array(frames[: i + 1]) * C_HI, err, color=color, marker="o", ms=4, label=label)
    err_ax.axhline(TOL, color=MUTED, ls=":", lw=1.2)
    err_ax.text(N0 * C_HI, TOL * 0.8, "target: 1% NRMSE", va="top", fontsize=7, color=MUTED)
    err_ax.set(yscale="log", ylim=(1e-3, 3), xlim=(N0 * C_HI - 5, frames[-1] * C_HI + 5),
               xlabel=f"cumulative cost (one high-fidelity run = {C_HI:g})", ylabel="error vs true curve")
    err_ax.legend(loc="upper right", ncol=3)
    fig.suptitle(f"{n} high-fidelity runs  ·  cost {n * C_HI:g}", fontweight="bold")


# Hold the last frame so the end state is readable before the loop restarts.
anim = FuncAnimation(fig, draw, frames=list(range(len(frames))) + [len(frames) - 1] * 4)
with tempfile.TemporaryDirectory() as tmp:
    path = f"{tmp}/active_learning.gif"
    anim.save(path, writer=PillowWriter(fps=2), dpi=72)
    with open(path, "rb") as f:
        gif = base64.b64encode(f.read()).decode()
plt.close(fig)
HTML(f'<img src="data:image/gif;base64,{gif}" alt="GP mean and ±2σ band as runs are added: '
     f'active vs Sobol vs random on Forrester" style="max-width:100%">')

[5]:

Reading the animation. The active learner’s band collapses fastest. Each run goes to the widest part of the band, so it spends runs on the steep, curved right-hand side (around the minimum near x ≈ 0.76 and the rise to x = 1) and few on the flat left half. Sobol spreads its runs evenly, so the flat half gets as many runs as the hard region. Random points cluster and leave gaps, and the band stays wide inside them. One seed is anecdotal; the next cell repeats this over 8 seeds and counts the cost to reach the target.

[6]:

N_MAX = 32
COST_SEEDS = range(8)
ns = np.arange(N0, N_MAX + 1)


def error_curve(X):
    return np.array([heldout_metrics(fit_on(X[:n]), x, y)["nrmse"] for n in ns])


def runs_to_target(err):
    # Smallest n after which the error stays at or below TOL for the rest of the budget;
    # N_MAX + 1 (a lower bound) if the target is never reached for good.
    ok = err <= TOL
    hit = [i for i in range(len(ok)) if ok[i:].all()]
    return ns[hit[0]] if hit else N_MAX + 1


err = {k: [] for k in METHODS}
for s in COST_SEEDS:
    for k, X in nested_designs(s, N_MAX).items():
        err[k].append(error_curve(X))
err = {k: np.array(v) for k, v in err.items()}
# Reference: an evenly spaced grid. It is not nested (adding a run moves every point), so
# its count is only achievable if you know the right n in advance.
err["grid"] = np.array([[heldout_metrics(fit_on(np.linspace(0, 1, n)[:, None]), x, y)["nrmse"] for n in ns]])
to_target = {k: np.array([runs_to_target(e) for e in v]) for k, v in err.items()}
cost = {k: np.median(v) * C_HI for k, v in to_target.items()}

print(f"Cost until the GP stays within {TOL:.0%} NRMSE of the true curve (median of {len(COST_SEEDS)} seeds):")
for k, v in to_target.items():
    missed = int((v > N_MAX).sum())
    print(f"  {k:<7} {np.median(v):>5.1f} runs  cost {cost[k]:>4.0f}"
          + (f"   range {v.min()}-{v.max()} runs" if len(v) > 1 else "")
          + (f"   target not reached within {N_MAX} runs in {missed}/{len(v)} seeds" if missed else "")
          + (f"   active learning saves {1 - cost['active'] / cost[k]:.0%}" if k != "active" else ""))

Reading the plot. The bars are median costs and the whiskers the range over seeds (“+” marks a design that missed the target within 32 runs on some seed, so its true cost is higher). Active learning reaches the true curve at a clearly lower cost than the sequential Sobol and random designs, and it is also more consistent across seeds. The uniform grid comes close on this one-dimensional function, but it is a one-shot design: its count is only achievable if you knew in advance how many runs to buy. Adding one run to a grid moves every point, so growing a grid sequentially costs far more. Sobol and random can grow one run at a time but spread their runs blindly. The active learner grows one run at a time and puts each run where it is needed.

Two caveats. On this smooth 1-D function the gap is a few runs; it grows when the response has localized features in a larger domain (section 4 shows smaller gains on smooth, stationary 2- to 4-D problems). And the cost here is high-fidelity runs only. Section 9 cuts cost further by mixing in a cheap low fidelity.

## 4. Active vs passive designs

The real question is whether active learning beats a good passive design of the same size. Two baselines:

  • random: the same loop with uniformly random scores (so points are i.i.d. uniform, apart from the batch-diversity penalty);

  • Sobol: a one-shot scrambled Sobol design of each size, a strong space-filling baseline.

The metric is held-out NRMSE (RMSE divided by the test targets’ std, averaged over outputs) on 1,000 points.

## 6. Batch selection

When a simulator runs several jobs at once, ask(q) returns q points. Taking the top q scores puts the whole batch on one peak of the acquisition. select_batch instead picks greedily and multiplies the remaining scores by 1 - exp(-d² / 2l²) around each pick (local penalization). The default length scale l is the typical spacing of a space-filling design with as many points as the data plus the batch.

## 8. Query-by-committee

Models such as KNN, linear models or plain trees have no predictive std; BaseSurrogate.predict(return_std=True) returns zeros for them. The learner refuses that (predict_mean_std raises), because zero std would read as “perfectly known”. CommitteeSurrogate fits bootstrap copies of any model and uses their disagreement as the std. penalize_train=True also penalizes candidates near existing points, because a committee’s spread does not reliably shrink at the training data.

## 9. Multi-fidelity active learning

With fidelity levels, each query is a pair (x, level) and the budget is in cost units. MultiFidelityActiveLearner asks how much of the high-fidelity predictive variance a run at each level would remove, per unit cost.

For the AR1 model AdditiveCorrectionVFM, f_hi = ρ f_lo + δ, so var_hi = ρ² var_lo + var_δ:

  • a low-fidelity run at x can remove ρ² var_lo(x);

  • a high-fidelity run (by default nested: the low fidelity is also run at the same point, and both costs are paid) removes all of var_hi(x).

The score is that reduction (standardized, summed over outputs) divided by the query’s cost. Two safeguards keep the cheap level from absorbing the budget when it does not deserve to:

  • level trust: a lower level’s credit is multiplied by the squared lower confidence bound of its correlation with the high-fidelity data, which is zero until there are 6 high-fidelity points;

  • ``min_hi_fraction`` (default 0.25): a high-fidelity query is forced whenever high-fidelity spending falls below that share of the total.

The baselines spend the same budget only on the high fidelity: active (max variance) and random.

[14]:

def ar1():
    return AdditiveCorrectionVFM(lo_surrogate_cls=gp, hi_surrogate_cls=gp, oof_cv=None)


def at_costs(hist, grid):
    # Error of the latest model fitted within each cost on the grid (step function).
    cost = np.array([h["cost"] for h in hist])
    err = np.array([h["nrmse"] for h in hist])
    return np.array([err[cost <= c][-1] if np.any(cost <= c) else np.nan for c in grid])

What the safeguards do and do not fix. They fix the spending: with the defaults most of the budget goes to the high fidelity instead of the noise. They do not fix the model: AdditiveCorrectionVFM still fuses the noise level through ρ f_lo, so its error stays erratic and can jump when a late low-fidelity run refits ρ. ## 10. Summary

  • Max-variance active learning is a sound default for global accuracy with a GP, but on smooth, stationary problems a Sobol design of the same size is nearly as good. The gains are modest here; the loop’s other features (stopping, batches, costs) carry much of the value.

  • Cost to replicate the true curve: starting from 3 runs on Forrester, max-variance active learning reaches 1% NRMSE at a clearly lower cost than growing a Sobol or random design one run at a time, and its ±2σ band shows where the remaining error is.

  • Standardize before aggregating outputs. With per-output stationary GPs it hardly changed the result on Branin–Currin, but without it the acquisition depends on the outputs’ units; it matters once outputs have different models or length scales.

  • Batches need diversity. Plain top-k puts the whole batch on one peak.

  • EI / UCB close in on the optimum of Branin and Hartmann-3 within a few dozen runs, far ahead of random search.

  • Query-by-committee brings models without native uncertainty into the loop, but a bootstrap KNN committee gave no gain over random points.

  • Multi-fidelity: on Currin and Park, cost-aware selection reaches a given high-fidelity error at a fraction of the cost of the high fidelity alone; on 1-D Forrester it does not help. The trust factor and high-fidelity floor stop a useless cheap level from absorbing the budget, but dropping such a level from the model is still to do.
